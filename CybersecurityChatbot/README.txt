# Cybersecurity Awareness Chatbot

## Description
A WPF-based Cybersecurity Awareness Chatbot built in C# that educates users about
cybersecurity topics through an interactive GUI interface.

## How to Run
1. Open the solution in Visual Studio 2022
2. Ensure the `greeting.wav` file is in the `bin/Debug/net8.0-windows/` folder
3. Press F5 or click the Start button to run the application

## Features
### Part 1
- Voice greeting on startup
- ASCII art logo
- Basic cybersecurity responses

### Part 2
- WPF Graphical User Interface
- Keyword Recognition (password, phishing, privacy, malware, scam, safe browsing)
- Random Responses for varied interactions
- Conversation Flow (follow-up questions)
- Memory and Recall (remembers user name and favourite topic)
- Sentiment Detection (worried, frustrated, curious, confused)
- Error Handling for unknown inputs
- OOP code structure with separate classes

## Technologies Used
- C# (.NET 8)
- WPF (Windows Presentation Foundation)
- winmm.dll for audio playback
